سامانه سربازان امام زمان

نسخه جدید سامانه با Python و پایگاه داده SQLite آماده است؛ اما GitHub Pages فقط فایل‌های ایستا را اجرا می‌کند و میزبان اجرای Python نیست.

۱. مخزن را به یک میزبان Python مانند Render متصل کن.
۲. فایل render.yaml را Deploy کن و ایمیل و رمز مدیر را در Environment وارد کن.
۳. پس از انتشار، نشانی سرویس پایتون را برای ورود اعضا استفاده کن.

راهنمای کامل فارسی در فایل README_FLASK_FA.md قرار دارد. برای نگهداری امن اطلاعات، دیسک پایدار لازم است.
