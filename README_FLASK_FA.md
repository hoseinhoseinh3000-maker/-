# سامانه سربازان امام زمان — نسخه Flask

این نسخه با Python، Flask و SQLite اجرا می‌شود. GitHub Pages به‌تنهایی قادر به اجرای Python نیست؛ برای آنلاین‌شدن باید سرویس Python روی یک میزبان جداگانه Deploy شود.

## امکانات
- ورود مدیر و اعضا
- درخواست عضویت بدون ثبت‌نام مستقیم
- تأیید یا رد درخواست توسط مدیر؛ حساب فقط هنگام تأیید ساخته می‌شود
- هش امن رمزها با Werkzeug
- پیام‌ها و اطلاعات خصوصی هر عضو
- ساخت عضو توسط مدیر، غیرفعال‌سازی حساب، اطلاعیه عمومی و تغییر رمز
- محافظت فرم‌ها با CSRF و کوکی‌های امن

## انتشار با Render
1. وارد Render شو و New → Blueprint را انتخاب کن.
2. مخزن GitHub را متصل کن و فایل render.yaml را Deploy کن.
3. در Environment سرویس، ADMIN_EMAIL و ADMIN_PASSWORD را وارد کن. رمز را یکتا و حداقل ۱۶ نویسه انتخاب کن.
4. پس از Deploy آدرس onrender.com را باز کن و با حساب مدیر وارد شو.
5. رمزها و کلیدهای محرمانه را در کد یا مخزن عمومی ننویس.

نکته: این تنظیم از دیسک دائمی برای SQLite استفاده می‌کند. دیسک پایدار Render معمولاً نیازمند پلن پولی است؛ سرویس رایگان با فایل‌سیستم موقت برای نگهداری داده واقعی مناسب نیست و ممکن است داده‌ها را از دست بدهد.

## اجرای آزمایشی ویندوز
Python 3.10 یا جدیدتر نصب باشد:
1. در پوشه پروژه اجرا کن: pip install -r requirements.txt
2. در CMD بنویس:
   set ADMIN_EMAIL=admin@example.com
   set ADMIN_PASSWORD=یک-رمز-قوی-و-طولانی
   python app.py
3. در مرورگر باز کن: http://127.0.0.1:5000

## امنیت و محدودیت‌ها
- حساب مدیر در اولین اجرا از متغیرهای محیطی ADMIN_EMAIL و ADMIN_PASSWORD ساخته می‌شود.
- برای استفاده واقعی HTTPS و دیسک دائمی لازم است.
- ایمیل یا پیامک خودکار ارسال نمی‌شود؛ مدیر باید رمز موقت را امن به عضو تحویل دهد.
- از فایل پایگاه داده sarbazan.db نسخه پشتیبان بگیر.
