# سامانه سربازان امام زمان

نسخه مخصوص GitHub Pages + Supabase.

- فرانت‌اند استاتیک فارسی (HTML/CSS/JavaScript)
- ورود با ایمیل و رمز از Supabase Auth
- پنل مدیر و پنل اختصاصی اعضا
- جداسازی داده‌ها با PostgreSQL Row Level Security (RLS)
- ایجاد عضو جدید از طریق Edge Function امن (کلید محرمانه فقط سمت سرور)

## راه‌اندازی
راهنمای کامل فارسی را در فایل `SETUP_FA.md` بخوانید.
**هرگز Supabase Secret/Service Role Key را در فایل‌های عمومی GitHub قرار ندهید.**
