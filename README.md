# سربازان امام زمان — سامانه یکپارچه فرهنگی

وب‌سایت فارسی، واکنش‌گرا و مبتنی بر GitHub Pages + Supabase.

## امکانات
- ورود اختصاصی مدیر و اعضا
- فرم عمومی درخواست ساخت حساب بدون ثبت‌نام آزاد
- صف درخواست‌ها در پنل مدیر
- تأیید درخواست توسط مدیر و ایجاد حساب Auth با رمز موقت یک‌بارنمایش
- رد درخواست بدون ایجاد حساب
- پیام‌ها و اطلاعات خصوصی در پنل اختصاصی هر عضو
- اطلاعیه عمومی
- Row Level Security و محدودسازی دسترسی داده‌ها در پایگاه داده
- Edge Functions برای عملیات حساس سمت سرور
- محدودسازی تعداد درخواست عمومی و فیلد honeypot ضدربات
- طراحی فارسی، راست‌چین، واکنش‌گرا و تیره

## نصب
راهنمای کامل مرحله‌به‌مرحله: SETUP_FA.md

هشدار: GitHub Pages فقط front-end استاتیک را اجرا می‌کند؛ احراز هویت و پایگاه داده به Supabase نیاز دارند. تا وقتی Supabase و سه Edge Function تنظیم و منتشر نشده‌اند، ورود/درخواست حساب عملیاتی کامل نیست.

کلید Publishable را می‌توان در config.js گذاشت؛ کلید Secret/Service Role را هرگز در مخزن یا مرورگر قرار ندهید.
